# Conversão técnica: veículos, mecânica, ciclismo e náutica

Tabela editorial PT-BR → PT-PT integrada na lista de vocabulário do plugin.
Não é um manual de reparação nem uma lista de termos brasileiros «incorretos»:
seleciona equivalentes adequados ao português europeu.

As entradas nominais abaixo incluem as variantes de plural explicitamente
registadas em `PortugueseWordList.xml`; não se inventam flexões.
As substituições respeitam maiúsculas, palavras ignoradas, entradas pessoais
e a opção de vocabulário. Os qualificadores fazem parte da regra:
por exemplo, **tanque de combustível**, não qualquer **tanque**.

## Arranque assistido: a expressão que motivou a revisão

| PT-BR ou tradução literal | PT-PT | Condição |
|---|---|---|
| dar uma chupeta no carro | dar arranque com cabos ao carro | *Dar* flexionado + objeto explícito: carro, moto, barco, motor ou outro veículo revisto |
| fazer uma chupeta no carro | fazer um arranque com cabos ao carro | *Fazer* flexionado + o mesmo objeto mecânico |
| dar uma chucha no carro | dar arranque com cabos ao carro | Recuperação da anterior tradução literal; nunca aplicada ao bebé |
| cabos de chupeta | cabos de arranque | Equipamento, não chupeta infantil |

Exemplo, com o passado e o complemento temporal preservados:

> Deu uma chupeta no meu carro no inverno passado.  
> Deu arranque com cabos ao meu carro no inverno passado.

O significado de *jump-started my car last winter* é um arranque assistido,
não uma chucha, um salto, um arranque por empurrão ou uma simples recarga completa.
A regra `transport-vocabulary` corre antes da conversão geral
**chupeta → chucha**. Funciona sem inglês quando a construção portuguesa explicita
o veículo. Não tenta adivinhar o significado de uma «chupeta» isolada.

## Distinções deliberadamente preservadas

| Termo | Motivo para não substituir indiscriminadamente |
|---|---|
| roda / jante / pneu | São componentes diferentes; *roda* não equivale sempre a *jante* |
| sistema de ignição / motor de arranque | Ignição e arranque têm funções distintas |
| câmbio | Pode ser financeiro; exige qualificador mecânico na nova tabela |
| marcha | Pode ser andamento, marcha militar ou manifestação |
| bateria | Pode ser musical, elétrica ou um conjunto de objetos |
| corrente | Pode ser elétrica, de transmissão, de água ou uma corrente metálica |
| vela | Pode ser de ignição, náutica ou de iluminação |
| coroa / pinhão / cassete | Componentes distintos; não se substituem uns pelos outros |
| pedivela | Pode designar um braço ou um conjunto; só o conjunto explícito é convertido |
| tanque | Pode ser militar, reservatório ou tanque de lavar |
| popa / proa / bombordo | Termos náuticos válidos em ambas as variedades |
| motor / hélice / leme / quilha | Termos partilhados; nenhuma mudança necessária |
| alternador / radiador / amortecedor / filtro de óleo | Termos partilhados; nenhuma mudança necessária |
| câmara de ar / pneu furado / macaco hidráulico | Termos partilhados; nenhuma mudança necessária |
| chupeta do bebé | Mantém a conversão literal **chucha** |
